# Manifestation-Gurus

New content pillar, decided 2026-08-13, built on the existing "Meditate
with Me" channel (@meditatewithme4897) — real audience already there
(~10K subs), real problem already diagnosed (existing 190 videos are
reposted guru clips, likely the cause of the channel's "not unique
enough" monetization flag, and a real copyright exposure on their own).

## Premise

Randy studied manifestation/law-of-attraction content for 5+ years —
genuinely, not as a hater. The angle: name the actual mechanism these
gurus use to make their claims unfalsifiable (if it works, the method's
proven; if it doesn't, you didn't do it right), aimed at the real,
documented audience of people burned out on Abraham Hicks/Dispenza/
Bob Proctor-style content but still hopeful something real exists.

## Real legal guardrail — locked, not optional

A February 2026 federal ruling (Cordova v. Huneault, N.D. Cal.) found
that ripping/downloading clips for reaction content can violate the
DMCA's anti-circumvention rule — separate from and not excused by fair
use on the commentary itself. **Don't rip or download guru footage.**
Build commentary from Randy's own paraphrase/description of what these
teachers claim, delivered in his own voice/avatar. A properly embedded
(not ripped) clip is fine only when a specific quote genuinely needs it,
kept short, with commentary as the clear majority of the video.

## Production approach

Voiceover or HeyGen avatar commentary, using the existing pipeline
already built in this project (`long-form-video-production` /
`youtube-shorts` skills). No raw guru footage required — this is
Randy's own analysis, not a reaction/compilation format.
