# The Texas Landlord Survival Guide — DRAFT (Validate stage)

Status: **Stage 1 draft (20-Minute MVP rule — Validate).** This is the
fastest complete version that proves the guide works as a product, built
from real, already-verified source material. Not yet polished for sale,
not priced, not on a platform. See `memory/project_texas_landlord_paid_product.md`
for the full research/citation trail this draft is built from.

## What's in this folder

1. **`01_the_485_moreland_playbook.md`** — Randy's real 485 Moreland
   eviction/abandonment story, told as a numbered playbook: each real
   decision point becomes a lesson with the citation that backs it up.
2. **`02_the_faq_bank.md`** — 7 real landlord questions (from the actual
   source material, already answered with verified citations), formatted
   in the "8-year-old summary + professional citations" style that's
   already working in the live Facebook group.
3. **`03_the_prompt.md`** — the actual prompt readers get to run their own
   questions through, safety-tightened (admin-assistant framing, not
   "legal advisor" framing) per the UPL discussion in the research phase.
4. **`DISCLAIMER.md`** — the locked disclaimer text, meant to appear on
   every product page, every answer, every document in this guide.
