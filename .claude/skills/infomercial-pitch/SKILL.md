# Infomercial Pitch

A concrete script-writing template, distilled from Randy's own real edit of a
teleprompter script (2026-07-31) for pitching The Riddle of Steel guidebook.
This is the execution-level format — the underlying theory of *why* this
works (persona, one-sentence pitch, live demo, right platform) already lives
in `reference_showmanship_pattern_library.md` (the Pet Rock/Snuggie/ShamWow
research). This skill is the literal template to follow when writing the
actual lines.

**Toolkit, not a formula** — same standing rule as the Carlin/Paul/war-story
toolkit in `youtube-script`/`youtube-shorts`: this is one available style,
not mandatory. Use it when pitching a real product/tool's features. Don't
force it onto content that isn't a feature pitch.

## The exact structure, per feature

```
Get [catchy, branded-sounding name for the feature] —

[one plain-language sentence: what it actually is/does]

Why This Is Valuable to You

[Benefit label]:

[short, second-person payoff sentence — "you" as the subject]

[Benefit label]:

[short, second-person payoff sentence]

[Benefit label]:

[short, second-person payoff sentence]

-------------------------------------------------------------
```

Repeat this block for each real feature in the product. Typically 3 benefit
labels per feature, occasionally 4 for a richer feature — never invent a
4th just to fill space.

## Rules, non-negotiable

1. **Name the feature like a product, not a document.** "AI-Proof Tech
   Checklist," not "the audit worksheet section." The name itself is part
   of the pitch — same instinct as Snuggie/ShamWow naming their ordinary
   object something memorable.
2. **Exact header line: "Why This Is Valuable to You."** Repeated
   identically every time — it's the rhythm marker, not a place to vary
   the wording.
3. **Every benefit label ends in a colon, then a short punchy sentence.**
   Second person always — "you learn," "you discover," "you get" — never
   third person or passive voice.
4. **One clause per line — this is a teleprompter script, not prose.**
   Every sentence fragment gets its own line so it reads as a natural
   breath/pause point when spoken aloud walking. Don't write paragraphs;
   break every sentence at its natural pause point.
5. **A divider line between every feature block** (a row of dashes) — keeps
   the blocks visually distinct when scrolling the teleprompter.
6. **At least one mid-pitch escalation**, verbatim or close to it: "But
   wait, there's more" — the classic infomercial re-hook, placed between
   feature blocks partway through, not at the very start.
7. **Close with the real price/offer stated directly, then a short
   imperative CTA.** "It's completely free. Get It Now!" is the reference
   example — adapt the specific wording to the actual offer (a real price,
   a real free-vs-paid distinction), but keep the shape: state the deal
   plainly, then one short command.
8. **Never invent features or benefits that aren't real.** Pull every
   feature from the actual product/guide/tool being pitched — this is a
   formatting/rhythm template, not a license to embellish what the thing
   actually does.

## When to use vs. when not to

Use for: pitching a real product/lead magnet/tool's actual features in a
walk-and-talk or avatar video, especially when reading off a phone
teleprompter mid-take.

Don't use for: a build/demo video (the build IS the content, this format
would flatten it), a war-story-led video, or anything where the "sell me
this" energy would feel mismatched to the topic.
