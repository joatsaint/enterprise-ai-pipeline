# Long-Form Script — Reaction-to-Source Recipe (~8 minutes)

The long-form version of `shorts-script`'s recipe — same DNA, same source
discipline, timestamps lengthened for a real ~8-minute video instead of a
60-75s Short. Built and proven once already: the "43% of CEOs" long-form
script (`video-production/long-form/43-percent-ceos-junior-cuts/`).

**Read `shorts-script/SKILL.md` first** — the Ingredients, hook library, and
Gotchas sections are shared and not repeated here. This file only covers
what's different at long-form length. That includes the Topic Sourcing
step (the 4 rotating search terms for the locked lane) — no separate
version needed here.

## When to use this vs. the alternatives

- **Reacting to a real Reddit thread/article, ~8 minutes** → this skill.
- **A tutorial/how-to/build walkthrough, any length** → `youtube-script`
  instead (6-segment Friction Hook structure, TTS formatting rules, video
  title framework — genuinely different genre, don't blend the two).
- **Same recipe, Shorts length** → `shorts-script`.
- **General long-form production pipeline** (HeyGen avatar chaining, screen
  recording, CapCut assembly) → `long-form-video-production` — that skill
  owns the PIPELINE; this skill owns the SCRIPT-WRITING step inside it.

## What's different at long-form length

Long-form earns room the Short doesn't have: real proof (more than one
quote), a credentials beat, and a fuller close — adapted from David Frey's
12-step sales-letter skeleton (via the jaredrhod-marketing skill), compressed
to fit the reaction-video shape rather than run as a literal checklist.

## Style Selection (before writing beats)

Run `style-selector` (`.claude/skills/style-selector/SKILL.md`) once the
source/tension/reframe are gathered — the extra room at this length makes
`guide-positioning`'s full pattern (not just stage 3) more likely to fit
than it would at Shorts length. Recommending none is still a valid outcome.

## Timestamps — ~8 minutes total (480s)

```
[0:00–0:15]  HOOK — same principle as Shorts: quote the source directly,
             flat and factual delivery, let the real number/claim be the
             shock. Don't oversell it with tone.

[0:15–1:00]  THE PROBLEM — state the real stat/claim plainly. Give it room
             to land before reacting to it.

[1:00–2:30]  THE REAL THREAD, THE REAL REACTION — this is where long-form
             earns its length over Shorts: pull MULTIPLE real quotes from
             the source's comment section, not just one. Include a genuine
             historical parallel or outside data point if one exists (the
             43%-CEOs script used a real 2008-recession parallel a commenter
             raised). If this is an avatar-narrated video, the Phigmund/
             Figment disclosure lands at a cliffhanger inside this section —
             same placement rule as Shorts, see reference_mccoy_avatar_intro_pattern.

[2:30–4:00]  THE REFRAME — the actual thesis. Name the pattern nobody in the
             source thread said out loud. Give this section real room — it's
             the core of the video, don't rush into the warning section.

[4:00–5:00]  THE WARNING — what should actually worry the viewer, stated
             honestly, both sides if there are two (e.g. "if you're
             early-career... if you're already established...").

[5:00–6:00]  THE OFFER — bridge to the CTA. Frame it as answering the exact
             gap the reframe just named, not a bolted-on pitch.

[6:00–7:00]  CREDENTIALS — why listen to Randy on this specifically. Short,
             concrete, real war-story grounded — never a résumé recitation.
             One paragraph, not a section.

[7:00–7:45]  CLOSE + CTA — restate the real thesis in one line, then the
             standard CTA.

[7:45–8:00]  P.S. (spoken close) — one more human line, not a repeat of the CTA.
```

## Citation discipline (matters more at this length)

Long-form videos make more factual claims than a Short — every stat pulled
from the source thread's own submission statement needs independent
verification before the video is treated as ready (same standard as
Citation Guard for articles). The 43%-CEOs script's Oliver Wyman stat was
verified independently via WebSearch before being treated as safe to cite
on screen — do this same step for any real number the script leans on.

## Plating

`video-production/long-form/<slug>/script.md`, matching the folder
convention already used for both the "43% of CEOs" script and the
HeyGen-avatar pipeline in `long-form-video-production`.

## Gotchas

- Don't blend this with `youtube-script`'s 6-segment tutorial structure —
  they're different genres solving different problems. A reaction video
  forced into the Friction-Hook/Step-by-Step shape reads as a tutorial with
  no actual steps; a build tutorial forced into this recipe loses the
  walkthrough it needs.
- The credentials beat should stay ONE paragraph — long-form's extra room is
  for the source material and the reframe, not for expanding Randy's bio.
- See `shorts-script/SKILL.md`'s Gotchas for the shared rules (disclosure
  placement, citation verification, CTA default) — not repeated here.
